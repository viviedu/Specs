# Specs

CocoaPod Specs for iOS/macOS

SDK compiled with https://github.com/webrtc-sdk/libwebrtc/blob/e10d33c06c9c908d4f04f11540f4cd4ad3fad25f/build/xcframework_dynamic_build.sh

## How to use

Use the following lines near the top of your Podfile

```podspec
source 'https://github.com/webrtc-sdk/Specs.git'
```

```podspec
pod 'WebRTC-SDK', '=125.6422.06'
```
